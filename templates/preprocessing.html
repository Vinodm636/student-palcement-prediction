📊 Outlier Detection & Capping
Applied IQR method on continuous score columns (aptitude, logical, English, communication, GD). Outliers are capped (Winsorized) rather than removed, preserving row count while reducing extreme value influence on model training.

Rule: Values outside [Q1 − 1.5×IQR, Q3 + 1.5×IQR] are clipped to the boundary.
{{ pre.outliers_capped }} Values Capped Method: IQR Winsorization
5
🏷️ Label Encoding
Categorical features (branch name) are label-encoded into numeric form for algorithms that require numeric input (SVM, KNN, Logistic Regression).

Tree-based models (RF, GBM) can handle categories natively, but a unified encoding ensures consistent input across all 8 classifiers.
Branch → Integer (0–7) internship_done → 0/1
6
⚖️ Feature Scaling (StandardScaler)
Applied Z-score standardisation (zero mean, unit variance) to all features. This is critical for distance-based and gradient-based algorithms:
• SVM — kernel distances are scale-sensitive
• KNN — Euclidean distance biased by large scales
• Logistic Regression — gradient convergence requires scaling
Tree-based models are scale-invariant but unified scaling is maintained.
Method: StandardScaler Applied to all {{ raw_cols + 7 }} features
